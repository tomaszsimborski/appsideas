# appsideas

- [beatbox-grid](beatbox-grid/): turns vocal beatboxing ("tu" kick, "ta" snare, "ts" hi-hat) into a drum step-sequencer grid, with a metronome and count-in. Open `beatbox-grid/index.html` in Chrome, or on a phone: <https://tomaszsimborski.github.io/appsideas/beatbox-grid/> (once GitHub Pages is enabled for `Main`).
